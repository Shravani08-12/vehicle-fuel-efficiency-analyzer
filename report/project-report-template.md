# Vehicle Fuel Efficiency Analyzer — Short Report Template

## 1. Problem statement
A manufacturer claims that a car model gives a mean mileage greater than 18 km/L. This project demonstrates statistical methods to analyze mileage and explore its relationship with engine capacity, speed and fuel type.

## 2. Data source and method
The current project uses 240 **simulated educational records** generated by `generate_data.R` with a fixed random seed. Variables are mileage (km/L), engine capacity (cc), average speed (km/h), fuel type (Petrol/Diesel), and mileage category (Low/High). This is not real manufacturer data.

## 3. Methods and hypotheses
- **P4 — one-sided mean test:** H0: μ = 18; H1: μ > 18. The app displays an approximate z statistic using the sample SD because a known population SD is not supplied. This limitation should be stated in the presentation.
- **P8 — sign test:** H0: population median = 18; H1: population median ≠ 18. Ties at 18 are excluded.
- **P6 — simple linear regression:** mileage = β0 + β1(engine capacity) + error. Examine the slope, p-value and R².
- **P3 — 95% confidence interval:** use the t interval when population SD is unknown; use the z interval only when a known population SD is justified.
- **P9 — Mann–Whitney/Wilcoxon rank-sum test:** H0: petrol and diesel mileage distributions are equal; H1: they differ.
- **P7 — chi-square test of independence:** H0: fuel type and mileage category are independent; H1: they are associated.

## 6. Limitations
The dataset is simulated; it may not represent actual vehicle populations. Regression is associational, and the z-test requires a known population SD for the exact textbook procedure.
